# Слово by Soulance

Диктовка на русском для Mac и Windows. Нажимаете клавишу, говорите, и текст появляется в том
поле, где стоит курсор: в мессенджере, почте, документе. Речь распознаётся на вашем компьютере,
в интернет ничего не уходит.

## Скачать

Все файлы — на странице [последней версии](https://github.com/Soulance-AI-Platform/slovo-download/releases/latest).
Выберите один, под свой компьютер:

| Компьютер | Файл |
|---|---|
| Mac на чипе Apple (M1, M2, M3, M4…) | `slovo_mac_apple-silicon.dmg` |
| Mac на процессоре Intel | `slovo_mac_intel.dmg` |
| Windows | `slovo_windows_x64-setup.exe` |

Какой у вас Mac: меню  → «Об этом Mac». Если в строке «Чип» написано Apple M…, берите
apple-silicon, если в строке «Процессор» написано Intel — intel.

## Установка на Mac

1. Откройте скачанный `.dmg` и перетащите «Слово by Soulance» в папку «Программы».
2. Запустите приложение. Mac покажет предупреждение, что не может проверить разработчика,
   — нажмите «Готово».
3. Откройте «Системные настройки» → «Конфиденциальность и безопасность», прокрутите вниз и нажмите
   «Открыть всё равно» напротив «Слово by Soulance». Подтвердите паролем.
4. При первом запуске разрешите доступ к микрофону и «Универсальный доступ»: без него Слово не
   сможет вставлять текст за вас.
5. Приложение предложит скачать русскую модель распознавания (около 160 МБ). Дальше интернет не
   нужен.

Если Mac пишет, что приложение повреждено, откройте «Терминал» и выполните:

```
xattr -cr "/Applications/Слово by Soulance.app"
```

После этого запустите приложение снова.

## Установка на Windows

1. Запустите скачанный `setup.exe`.
2. Windows может показать синее окно «Windows защитил ваш компьютер». Нажмите «Подробнее», затем
   «Выполнить в любом случае».
3. Пройдите установку и разрешите доступ к микрофону, когда Windows спросит.

## Почему такие предупреждения

Приложение пока не подписано сертификатами Apple и Microsoft. Система предупреждает о любой
программе без такой подписи, вирусов в ней нет. Подпись появится в следующих версиях.
